## Учебная цель

Ученик решает показательное неравенство: приводит обе части к одному основанию, сравнивает
показатели и **выбирает направление знака по основанию** — при `a > 1` знак сохраняется, при
`0 < a < 1` переворачивается; записывает ответ промежутком и проверяет его точкой внутри и
точкой снаружи.

## Опоры (экран 2)

1. `64 = 2⁶`, `1/64 = 2⁻⁶`, `81 = 3⁴` — одно число разными основаниями.
2. `0,5 = 2⁻¹`, `1/9 = 3⁻²` — дробное основание это отрицательный показатель.
3. При `a > 1` функция растёт, при `0 < a < 1` убывает — на графике двух кривых.

## Пять заблуждений

| Код | Заблуждение | Как выглядит | Тег |
|---|---|---|---|
| З1 | не перевернул знак при основании меньше единицы | `(0,5)ˣ < 1/64` → `x < 6` | `base_direction` |
| З2 | сравнил показатели, не приведя к одному основанию | `(1/9)ˣ < 1/27` → `x < 3` | `same_base` |
| З3 | потерял минус в дробном основании | `0,5 = 2⁻¹` прочитано как `2¹` | `neg_exponent` |
| З4 | забыл, что деление на отрицательное тоже переворачивает знак | `−2x < −3` → `x < 1,5` | `base_direction` |
| З5 | не проверил ответ | шаги верны, точка не подставлена | `check_by_point` |

Новых тегов не нужно — все четыре уже в эталоне §5.

### Ключевые кадры

**Экран 3.** Три точки, и третья — граница. `x = 7`: `(0,5)⁷ = 1/128`, и одна сто двадцать
восьмая меньше одной шестьдесят четвёртой — входит. `x = 5`: `1/32`, это больше — не входит.
`x = 6`: ровно `1/64`, а знак строгий — **граница не входит**. Третья точка нужна: без неё
ученик решит, что проверка только подтверждает.

**Экран 4.** Кривая `y = (0,5)ˣ` падает. Прямая `y = 1/64` пересекает её при `x = 6`. Нам
нужно, где кривая **ниже** прямой — и это оказывается **справа** от точки. Вот весь
переворот знака, увиденный, а не заученный: у убывающей «меньше значение» значит «правее».

**Экран 7.** `0,4^(x²−x−20) > 1`. Единица справа — это `0,4⁰`. Проверка без вычислений:
при `x = 0` показатель равен минус двадцати, а дробь в отрицательной степени больше единицы —
входит. При `x = 6` показатель равен десяти, дробь в положительной степени меньше единицы —
не входит. Отсюда `x² − x − 20 < 0` и ответ `(−4; 5)`.

**Экран 11 без прямой.** `(1/9)ˣ < 1/27`. Две ловушки сразу: сначала дробное основание
(`1/9 = 3⁻²`), потом деление на отрицательное (`−2x < −3`). Разбор идёт только числом.
