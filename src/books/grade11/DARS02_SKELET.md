# Урок 2. Правила — раскадровка

Статус: **редакция 1 от 2026-08-15.** Контракт — `ETALON_11SINF.md`.
**Отступление от эталона: ноль экранов.** Второй урок блока Б1.

## Что этот урок добавляет к первому

Урок 1 дал одно правило — степенное — и один инструмент проверки: продифференцируй и
сравни. Урок 2 достраивает до рабочего набора **три правила**:

| | Правило | Где в учебнике |
|---|---|---|
| П1 | постоянный множитель проходит насквозь: `a·f → a·F` | ч. 1, «Правило 1» |
| П2 | слагаемые считаются по отдельности: `f ± g → F ± G` | ч. 1, «Правило 2» |
| П3 | скобка `kx + b`: `f(kx+b) → F(kx+b) / k` | ч. 1, таблица интегралов, строка 15 |

**Порядок отличается от учебника осознанно.** В учебнике правила стоят в параграфе
«Таблица интегралов. Простейшие правила интегрирования», то есть **после** знака
интеграла. В нашем плане урок 2 «Правила» идёт **до** урока 3 «Неопр. интеграл».
Поэтому правила формулируются в терминах первообразной (`F`), а не значка `∫`. Смысл
тот же, запись доступна ученику, который знака интеграла ещё не видел.

**Право на П3 проверено по учебнику.** Производная сложной функции — параграф уроков
10–12 первой части, и там же пример «найдите производную: `(kx+b)ⁿ`, `sin(kx+b)`,
`cos(kx+b)`, `tg(kx+b)`». Значит ученик умеет дифференцировать скобку, и весь урок
проверяем в уме.

**Тригонометрии в уроке нет.** Первообразные синуса и косинуса — это строка таблицы,
которой у ученика пока нет: таблица приходит в уроке 3. Всё, что делается на уроке 2,
проверяется дифференцированием степени, то есть тем, что уже есть.

## Главная мысль урока

> **Лишний множитель гасят заранее. Откуда бы он ни пришёл — из показателя или
> из скобки.**

Урок 1 научил гасить множитель, приходящий из показателя (делим на `n + 1`). Урок 2
говорит: это частный случай. Скобка `2x + 1` при дифференцировании тоже выбросит наружу
двойку — значит на двойку надо поделить заранее. Одна мысль, два источника множителя.

### Задачи и сверка

Каждая строка проверена дифференцированием ответа.

| Задача | Ответ | Проверка |
|---|---|---|
| `f = (2x+1)²` двумя способами | `4x³/3 + 2x² + x + C` и `(2x+1)³/6 + C` | обе дают `4x²+4x+1`; разность равна `1/6` |
| `f = 6x²` | `2x³ + C` | `(2x³)' = 6x²` ✓ |
| `f = 10x⁴` | `2x⁵ + C` | `(2x⁵)' = 10x⁴` ✓ |
| `f = (2x+1)⁷` | `(2x+1)⁸/16 + C` | `8·(2x+1)⁷·2 / 16 = (2x+1)⁷` ✓ |
| `f = (3x−2)⁴` | `(3x−2)⁵/15 + C` | `5·(3x−2)⁴·3 / 15 = (3x−2)⁴` ✓ |
| `f = 4(3x+1)²` | `4(3x+1)³/9 + C` | `4·3(3x+1)²·3 / 9 = 4(3x+1)²` ✓ |
| `f = 10(2x−3)⁴` | `(2x−3)⁵ + C` | `5(2x−3)⁴·2 = 10(2x−3)⁴` ✓ |
| `f = (2x+7)³` | `(2x+7)⁴/8 + C` | `4·(2x+7)³·2 / 8 = (2x+7)³` ✓ |
| `f = (5x−1)²` | `(5x−1)³/15 + C` | `3·(5x−1)²·5 / 15 = (5x−1)²` ✓ |

Тип задач взят из упражнений учебника к этой теме (`(3x+2)²`, `(2x−1)³`, `1/(2x+3)`),
числа свои. Дробных первообразных вида `1/(kx+b)` в уроке нет: логарифм — тоже строка
таблицы из урока 3.

## Пять заблуждений

| Код | Заблуждение | Как выглядит | Тег |
|---|---|---|---|
| З1 | множитель попадает внутрь степени | `f = 6x²` → `F = 6x³` | `linearity` |
| З2 | скобку считают как обычный `x` | `f = (2x+1)⁷` → `F = (2x+1)⁸/8` | `inner_k` |
| З3 | делят на `k`, но не на новый показатель | `f = (3x−2)⁴` → `F = (3x−2)⁵/3` | `inner_k` |
| З4 | ответ, полученный другим способом, считают чужим | «раскрыл скобки — значит решил не так» | `plus_c` |
| З5 | не проверил дифференцированием | ответ не проверен, множитель потерян молча | `check_by_diff` |

Новых тегов два — `linearity` и `inner_k`, внесены в эталон §5.

### Ключевые кадры

**Экран 1 — хук про способ, а не про ответ.** Спорят не «верно и неверно», а два верных
решения, которые выглядят по-разному:

```
  первое решение:   раскрыл скобки       →  F = 4x³/3 + 2x² + x + C
  второе решение:   не раскрывал         →  F = (2x+1)³/6 + C
```

Верный ответ прогноза — **оба**. Разность двух записей равна `1/6`, то есть постоянной,
а постоянную урок 1 уже разрешил. Хук делает две вещи сразу: подтверждает `+ C` на
настоящем примере и ставит вопрос, ради которого урок существует, — **откуда взялась
шестёрка во втором решении**.

**Экран 3.** Спор закрывает дифференцирование, как в уроке 1. Три кандидата:
`4x³/3 + 2x² + x` даёт `4x² + 4x + 1`; `(2x+1)³/6` даёт `(2x+1)²` — это то же самое;
`(2x+1)³/3` даёт `2(2x+1)²` — вдвое больше. Два разных на вид ответа оказались одной
функцией с точностью до постоянной, а третий отпал по числу.

**Экран 4.** Две кривые: `x³/3` и `2x³`. Первая — первообразная для `x²`, вторая — для
`6x²`. Касательные в точке `x = 1`: наклон 1 и наклон 6. Растянули кривую по вертикали в
шесть раз — наклон везде вырос в шесть раз. Отсюда видно, почему множитель проходит
через первообразную нетронутым: он растягивает и функцию, и её наклон одинаково.
Это ровно тот же приём, что в уроке 1 (касательные к семейству), только там постоянная
двигала кривую и не меняла наклон, а здесь множитель наклон меняет — ровно во столько же
раз.

**Экран 7 — сердце урока.** Скобку в седьмой степени раскрывать никто не станет: восемь
слагаемых. Значит нужен способ. Два кандидата, оба дифференцируются на глазах:

```
  (2x+1)⁸ / 8   →   8(2x+1)⁷ · 2 / 8   =  2(2x+1)⁷    ✗ вдвое больше
  (2x+1)⁸ / 16  →   8(2x+1)⁷ · 2 / 16  =   (2x+1)⁷    ✓
```

Шестнадцать — это не «делим на 16», а `8 · 2`: восьмёрка из показателя, двойка из
скобки. Два множителя, оба гасятся заранее.

**Экран 9.** `(3x−2)⁴ → (3x−2)⁵ / ⬚`. Варианты 5, 3, 15. Пятёрка и тройка — это
половина ответа каждая: одна помнит про показатель и забыла скобку, другая наоборот.

**Экран 13.** Ошибка в середине, проверка выполнена и не прочитана:

```
  1)  f(x) = (3x + 2)⁴
  2)  F(x) = (3x + 2)⁵ / 5        ← ошибка: не поделено на 3
  3)  проверка: ((3x+2)⁵/5)' = 3(3x+2)⁴
  4)  ответ: F = (3x + 2)⁵ / 5
```

Строка 3 верна сама по себе и именно она уличает строку 2: получилось три скобки в
четвёртой степени вместо одной.
