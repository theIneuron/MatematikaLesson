# Методология преподавания математики в 8 классе

## 1. Возрастной переход

В 8 классе ученик переходит от выполнения знакомого алгоритма к системному
пониманию условий, структуры и доказательства.

Недостаточно:

- получить правильный ответ;
- повторить показанный образец;
- назвать формулу;
- узнать фигуру по внешнему виду.

Ученик должен уметь:

- распознать математическую структуру;
- установить условия применимости;
- выбрать способ и объяснить выбор;
- преобразовать модель без потери смысла;
- проверить крайние и запрещённые случаи;
- отличить наблюдение от доказательства;
- интерпретировать результат;
- перенести идею в новую форму.

Основной цикл:

> **поставь вопрос → выдвини гипотезу → исследуй → обоснуй → примени →
> проверь → перенеси**

---

## 2. Главные принципы

### 2.1. Новое понятие отвечает на возникшую проблему

Правило не появляется как произвольная информация. Старый способ должен:

- дать противоречие;
- оказаться слишком длинным;
- не учесть ограничение;
- не объяснить граничный случай;
- не позволить выполнить точное вычисление или доказательство.

### 2.2. Абстракция строится на примерах, но не сводится к ним

Путь новой алгебраической идеи:

```text
несколько специально подобранных числовых случаев
→ структурная закономерность
→ буквенная формулировка
→ контрпример
→ применение
```

Путь новой геометрической идеи:

```text
динамический чертёж
→ наблюдение и измерение
→ гипотеза
→ логическое обоснование
→ применение
```

### 2.3. Условие — часть знания

Формула без условия считается неполным знанием.

В каждом подходящем уроке ученик отвечает:

- когда выражение определено;
- когда преобразование равносильно;
- при каких данных теорема применима;
- какие корни нужно проверить;
- какой диапазон результата возможен;
- какая точность допустима.

### 2.4. Ошибка — диагностический объект

Ошибка показывает стратегию ученика. Методика должна определить не только
«неверно», но и вероятную причину.

### 2.5. Активность означает мышление

Нажатие кнопки и просмотр анимации не считаются активностью сами по себе.
Осмысленное действие требует:

- решения;
- выбора с основанием;
- прогноза;
- изменения модели;
- построения;
- объяснения;
- проверки;
- создания примера.

---

## 3. Актуализация прежних знаний

Каждый урок начинается с узкой проверки предпосылок.

Входная диагностика:

- занимает не более 2–4 минут;
- проверяет 1–3 конкретных навыка;
- не спрашивает новое правило;
- не выставляет итоговую оценку;
- включает короткое восстановление пробела.

Примеры предпосылок курса:

| Новая тема | Что проверить |
|---|---|
| Рациональные дроби | значение выражения, знаменатель, линейное уравнение |
| Квадратные корни | квадрат числа, площадь квадрата, неотрицательность |
| Квадратные уравнения | раскрытие скобок, приведение подобных, линейные уравнения |
| Неравенства | сравнение чисел, числовая прямая, действия с отрицательными числами |
| Стандартный вид | свойства степеней, десятичные дроби, порядок числа |
| Площади | основание, высота, площадь прямоугольника и треугольника |
| Подобие | отношения, пропорции, углы треугольника |

Если диагностика обнаружила пробел, урок даёт локальную опору, но не превращается
в полное повторение предыдущего класса.

---

## 4. Управляемое открытие

Управляемое открытие не означает, что ученик должен самостоятельно изобрести всю
математику.

Учитель или интерфейс:

1. подбирает вариативные примеры;
2. задаёт направление наблюдения;
3. фиксирует значимые результаты;
4. предлагает контрпример;
5. помогает сформулировать точный вывод.

Ученик:

1. делает прогноз;
2. выполняет математическое действие;
3. сравнивает случаи;
4. замечает связь;
5. проверяет границу;
6. завершает формулировку.

Открытие считается состоявшимся, если ученик может применить идею к новому
примеру до показа полного алгоритма.

---

## 5. Теория вариации

Примеры подбираются не случайно. Между соседними примерами изменяется один
значимый признак.

Для рациональных дробей:

```text
(x - 3)/(x + 1) при x = 3
(x + 1)/(x - 3) при x = 3
```

Изменяется положение множителя `x - 3`; ученик отделяет нулевой числитель от
нулевого знаменателя.

Для квадратного корня:

```text
√25
x² = 25
√((-5)²)
```

Ученик различает арифметический корень, корни уравнения и модуль.

Для геометрии:

- сохраняется параллельность, меняется длина стороны;
- сохраняются углы, меняется масштаб;
- сохраняются две стороны, меняется угол между ними;
- сохраняется внешний вид, нарушается обязательный признак.

В наборе должны присутствовать:

- пример;
- похожий непример;
- граничный случай;
- контрпример к типичной ошибке.

---

## 6. Разобранные примеры и снятие опоры

Для сложных процедур используется worked-example fading.

### Этап 1. Полный пример

Видны:

- цель;
- условия;
- шаги;
- основание каждого перехода;
- проверка.

### Этап 2. Пропущенное решение

Ученик выбирает:

- следующий шаг;
- применяемое свойство;
- необходимое ограничение.

### Этап 3. Пропущенные шаги

Остаётся только структура и короткая подсказка.

### Этап 4. Новый пример

Нет пошаговой опоры; ученик сам выбирает способ.

Нельзя после одного показанного примера сразу требовать серию полностью
самостоятельных сложных преобразований.

---

## 7. Чередование объяснения и действия

Урок строится короткими циклами:

```text
вопрос → действие → обратная связь → краткое объяснение
```

Запрещённая последовательность:

```text
восемь объяснений → восемь тестовых вопросов
```

Допустимая последовательность:

```text
прогноз
→ эксперимент
→ локальный вывод
→ новый случай
→ формализация
→ практика
→ ошибка
→ перенос
```

Не более двух пассивных экранов подряд. После сложного объяснения ученик должен
сразу использовать ключевую идею.

---

## 8. Методика алгебраических понятий

Для определения или свойства:

1. предъявить знакомые и новые объекты;
2. предложить классификацию или прогноз;
3. изменить один структурный элемент;
4. выявить существенный признак;
5. проверить контрпример;
6. сформулировать определение;
7. распознать объект в новой записи;
8. построить собственный пример и непример.

Особое внимание:

- области допустимых значений;
- знакам и скобкам;
- тождественности и равносильности;
- различию выражения, уравнения и функции;
- связи символической записи с таблицей и графиком.

---

## 9. Методика алгоритмов и преобразований

Для алгоритма:

1. определить цель преобразования;
2. активировать необходимое свойство;
3. показать полный пример с основаниями;
4. дать пример с выбором следующего шага;
5. сравнить два способа;
6. разобрать незаконный переход;
7. решить новый пример;
8. проверить результат подстановкой, обратным действием или оценкой.

Ученик не должен воспринимать знак равенства как команду «получить следующий
шаг». Каждая строка преобразования обязана быть равной или равносильной
предыдущей в заявленных условиях.

---

## 10. Методика уравнений и неравенств

Обязательные решения ученика:

1. определить тип математической модели;
2. выбрать преобразование;
3. назвать условие равносильности;
4. получить множество возможных решений;
5. проверить решения в исходной записи;
6. интерпретировать ответ.

Для неравенств отдельно проверяются:

- изменение знака при умножении или делении на отрицательное число;
- открытые и закрытые границы;
- объединение и пересечение промежутков;
- различие одного решения и множества решений.

Для дробно-рациональных уравнений проверка ОДЗ выполняется до преобразования и
возвращается на этапе проверки корней.

---

## 11. Методика геометрии

Геометрический урок проходит пять стадий:

1. **Наблюдение.** Ученик изменяет чертёж или сравнивает фигуры.
2. **Гипотеза.** Формулирует предполагаемую связь.
3. **Проверка случаев.** Измеряет и ищет контрпример.
4. **Доказательство.** Строит цепочку из данных, свойств и вывода.
5. **Применение.** Вычисляет или доказывает в новой конфигурации.

Правила:

- чертёж не обязан быть выполнен в масштабе;
- внешний вид не является доказательством;
- скрытые равенства не обозначаются заранее;
- вспомогательная линия появляется только с объяснением её цели;
- различаются «дано», «следует» и «нужно доказать»;
- каждое используемое свойство имеет основание.

Интерактивный чертёж помогает выдвинуть гипотезу, но доказательство строится
логически.

---

## 12. Методика статистики и комбинаторики

Статистический вывод строится по цепочке:

```text
вопрос → данные → способ представления → вычисление → интерпретация → ограничение
```

Ученик проверяет:

- отвечает ли набор данных поставленному вопросу;
- понятны ли единицы и шкала;
- нет ли пропусков или повторов;
- какое среднее уместно;
- не искажает ли диаграмма сравнение;
- не является ли вывод шире имеющихся данных.

В комбинаторике:

- сначала строится полный системный перебор;
- затем обнаруживается структура выбора;
- после этого формулируется правило умножения;
- ответ проверяется на малом случае.

---

## 13. Решение текстовых и модельных задач

Ученик принимает восемь решений:

1. Что требуется определить?
2. Какие данные существенны?
3. Какие величины и единицы используются?
4. Как связаны величины?
5. Какие ограничения следуют из контекста?
6. Какая математическая модель подходит?
7. Как проверить вычисление?
8. Как интерпретировать результат?

Ключевое слово не определяет действие. Схема или формула должна отражать связь
величин.

Если модель имеет несколько математических решений, ученик объясняет, какие из
них содержательно допустимы.

---

## 14. Доказательство и обоснование

В 8 классе различаются уровни:

1. **Наблюдение:** «На этих примерах получилось».
2. **Объяснение:** «Это происходит из-за свойства».
3. **Обоснование:** «Каждый переход следует из указанного условия».
4. **Доказательство:** «Утверждение верно для всех объектов данного класса».

Интерфейс использует явные маркеры:

- `Дано`;
- `Нужно установить`;
- `Гипотеза`;
- `Основание`;
- `Следовательно`;
- `Проверка`.

Не каждое задание требует полного формального доказательства, но каждый урок
требует хотя бы одного содержательного «почему».

---

## 15. Выбор стратегии

Минимум один раз в уроке ученик выбирает способ по условию задачи.

Примеры:

- привести к общему знаменателю или сначала сократить;
- применить формулу или распознать неполное квадратное уравнение;
- решить уравнение разложением или по формуле;
- представить решение промежутком или на числовой прямой;
- вычислить напрямую или использовать свойство;
- применить Пифагора, подобие, координаты или тригонометрию.

Обратная связь оценивает:

- корректность;
- эффективность;
- прозрачность проверки;
- применимость к данному случаю.

Если несколько способов равноценны, интерфейс не объявляет один из них
единственно правильным.

---

## 16. Работа с ошибкой

Обратная связь строится по схеме:

> **распознать стратегию → указать нарушенное условие → вернуть к действию**

Пример:

> Ты исключил значение, при котором числитель равен нулю. Проверь, какая часть
> дроби отвечает за допустимость выражения.

Уровни помощи:

1. вопрос о стратегии;
2. выделение значимого элемента;
3. напоминание свойства;
4. один разобранный шаг;
5. новый аналогичный пример.

После помощи ученик не просто нажимает «Далее», а выполняет исправленное действие.

---

## 17. Математическая речь

Ученик регулярно строит короткие точные объяснения:

- «Я исключил значение ___, потому что ___.»
- «Преобразование равносильно при условии ___.»
- «Измерения подтверждают гипотезу, но не доказывают её, потому что ___.»
- «Этот корень не подходит исходной модели, так как ___.»
- «Интервал открыт/закрыт, потому что ___.»
- «Способ ___ удобнее здесь, потому что ___.»
- «Результат разумен, поскольку ___.»

При выборе готовых частей:

- варианты должны быть грамматически совместимы;
- неверные комбинации отражают реальные ошибки;
- нельзя угадывать ответ по длине или форме.

---

## 18. Проверка и самоконтроль

После решения ученик выбирает подходящий метод проверки:

- подстановка;
- обратное действие;
- оценка порядка или диапазона;
- проверка исходного условия;
- второй способ;
- сравнение с графиком или таблицей;
- анализ единиц;
- проверка граничного случая;
- геометрическое обоснование.

Фраза «проверь ответ» без указания возможного инструмента допустима только после
того, как ученик освоил несколько методов проверки.

---

## 19. Интервальное повторение

Повторение распределяется внутри курса:

- в начале урока — точечное прежнее знание;
- внутри урока — связь с ранее изученным способом;
- в практике — одно перемешанное задание;
- через несколько уроков — новое применение;
- в конце блока — перенос между темами.

Перемешивание применяется после первичного понимания, а не вместо него.

Пример:

- ОДЗ из урока 1 возвращается при сокращении дробей;
- снова используется в дробно-рациональных уравнениях;
- затем сравнивается с ограничениями в неравенствах.

---

## 20. Дифференциация

Сложность математической цели остаётся общей. Меняется поддержка.

### При затруднении

- сократить объём одновременно видимых данных;
- вернуть числовой пример;
- выделить структурный элемент;
- дать речевую опору;
- показать один шаг;
- предложить аналогичный, но более простой случай.

### При уверенном выполнении

- попросить контрпример;
- изменить представление;
- предложить обратную задачу;
- сравнить способы;
- доказать обобщение;
- найти условие, при котором правило перестаёт работать.

Быстрое выполнение не является основанием для автоматического усложнения, если
стратегия нестабильна.

---

## 21. Структура практики

Банк из 10 заданий следует `ETALON_8SINF.md`.

Дополнительно:

- задания 1–3 проверяют основу;
- задания 4–7 требуют самостоятельного применения и выбора;
- задания 8–10 проверяют границу, ошибку и перенос;
- минимум одно задание возвращает идею прошлой темы;
- минимум одно требует математического объяснения;
- минимум одно не имеет вариантов ответа;
- вычислительная сложность не должна заслонять новое понятие.

---

## 22. Диагностическая модель

Оценивается не один общий процент, а профиль понимания:

| Компонент | Что наблюдаем |
|---|---|
| Понятие | Распознаёт ли существенный признак |
| Процедура | Выполняет ли преобразование |
| Условие | Учитывает ли ограничения |
| Представление | Переходит ли между формами |
| Стратегия | Выбирает ли подходящий способ |
| Обоснование | Может ли объяснить ключевой переход |
| Проверка | Контролирует ли результат |
| Перенос | Использует ли идею на новых данных |

Неудача в одном компоненте не превращается в ярлык «тема не усвоена». Следующее
задание или урок получает адресную опору.

---

## 23. Согласование с интерфейсом

Методический замысел должен быть реализуем:

- мышью;
- касанием;
- клавиатурой;
- с выключенным звуком;
- при `prefers-reduced-motion`;
- на ширине 390 px;
- на узбекском, русском и английском языках.

Если механика не может быть доступно перенесена на mobile, меняется механика, а
не учебная цель.
