## Урок: рациональные выражения и рациональные дроби

Класс: 8 · Экранов: 16 · Время: 28–35 минут · Языки будущего контента:
UZ / RU / EN.

Подход: проблема → гипотеза → числовой эксперимент → граничный случай →
открытие условия → формализация → снятие опоры → перенос.

Главный результат: ученик определяет запрещённое значение рациональной дроби по
знаменателю и объясняет, почему нулевой числитель допустим, а нулевой знаменатель
делает выражение неопределённым.

Граница урока:

- входит: тип выражения, числитель, знаменатель, значение выражения,
  условие `B(x) ≠ 0`, одно линейное ограничение;
- не входит: основное свойство и сокращение рациональной дроби, действия с
  дробями, несколько знаменателей, график рациональной функции;
- персонажей, маскотов, наград и детского сюжета нет;
- визуальная рамка — спокойная исследовательская среда `MATH.LAB 8`.

## Покрытие заблуждений

| Код | Заблуждение | Где проверяется |
|---|---|---|
| `M1` | Нулевой числитель делает дробь неопределённой | `s5`, `s11`, `s14` |
| `M2` | Деление на ноль даёт ноль | `s5` |
| `M3` | Для допустимости нужно проверять числитель | `s10`, `s11`, `s13` |
| `M4` | Любой нулевой результат нужно исключить | `s5`, `s14` |
| `M5` | Знаменатель появляется только после подстановки | `s10` |
| `M6` | Проверки нескольких значений достаточно для общего вывода | `s9` |
| `M7` | В `x + a = 0` запрещённым значением является `a` | `s9`, `s13` |
| `M8` | Любое буквенное выражение имеет запрещённое значение | `s10` |

Misconceptions сформулированы по школьной логике темы и материалам 8-го класса.
Перед production требуется предметная проверка методистом; терминология UZ и EN
проверяется отдельно на этапе content-generator.
