## 3. Чему учит урок

Ученик находит числа, при которых записи **не существует**, и записывает условие сам.
Три шага, которые повторяются весь урок и весь год:

1. посмотреть **под черту**;
2. найти число, обращающее знаменатель в нуль;
3. записать условие.

Ровно эти три шага сначала показывает программа (экран 3), потом делает ученик — на записи с
запретом (экран 4) и на записи, где запрета нет вовсе (экран 5).

### Прибор `Film` — лента кадров

Устройство взято у 4 класса дословно: сверху ОДИН объект, снизу лента кадров с подписями.

### Экран 1 — почему плоттер против таблицы

Факт правдив и проверяем: плоттер соединяет посчитанные точки и устранимый разрыв не
рисует. Значит «обе машины исправны, а ответы разные» — не выдумка. Четыре варианта
прогноза, у каждого неверного свой разбор; прогноз в тёплом камне, тега нет, зелёного нет.

Заодно хук с первой минуты вводит З2 — главное заблуждение года.

### Экраны 3 и 4 — показ и самостоятельная работа

Один и тот же прибор в двух режимах, поэтому ученик повторяет **ровно** то, что видел.

```
ЭКРАН 3 — ПОКАЗ                       ЭКРАН 4 — САМ
   (a + 5) / a       ☝                   (x + 1) / (x − 3)
шаг 1  прибор берёт знаменатель       шаг 1  ученик тапает знаменатель
шаг 2  нуль летит в дробь             шаг 2  ученик ищет число сам
       черта рвётся                          черта рвётся
вопрос значение есть или нет?         вопрос что происходит при трёх?
шаг 3  УЧЕНИК пишет  a ≠ 0            шаг 3  ученик пишет  x ≠ 3
```

Два вопроса по ходу демо обязательны: без ответа показ не идёт дальше. Последний шаг —
ОДЗ — прибор не пишет ни в одном из режимов (§2.2.1).

На экране 4 число ищет ученик: если оно не обращает знаменатель в нуль, поле остаётся
открытым и он берёт другое. Нужное число прибор не называет.

### Экран 8 — правило и возврат хука

Шесть фрагментов, четыре из них складываются в формулировку; два лишних взяты из
заблуждений («смотрят на числитель», «при которых он равен единице»). Только после верной
сборки открывается карточка учебника; пока закрыта — замок той же высоты.

Под карточкой возвращаются две машины с экрана 1: плашка плоттера гаснет, плашка таблицы
зеленеет. Вопрос хука получает ответ на экране 8, а не только на итоге.

### Экран 12 — устройство ловушки

```
1  x² − 4x
2  x² − 4x = x(x − 4)
3  x − 4 = 0,  x = 4        <- первая неверная: потерян множитель x
4  ОДЗ:  x ≠ 4
```

Строка 4 из строки 3 выводится верно, поэтому искать надо первую. Контрпример вводит
ученик: число `0`. Проверка идёт по записи `(x+1)/x`, то есть по потерянному множителю, —
значит `4` контрпримером не считается.
