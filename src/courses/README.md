# src/courses — дерево работы по новой схеме

> Точка входа в работу по 3 классу — [START_GRADE3.md](../../START_GRADE3.md) в корне проекта.
> Этот файл объясняет только устройство дерева.

## Зачем отдельное дерево

Уроки 1–8 классов писались как самодостаточные монолиты: в каждом файле своя копия
`AudioEngine`, стилей и базовых компонентов. В `src/components/grade2/` файл урока доходит
до 10 000 строк, а среднее совпадение соседних уроков — 93%. Исправление одного бага
означало 45 одинаковых правок.

Новая схема разделяет код и контент: код живёт в одном экземпляре (`kit/`), урок —
это данные (`content/`). Чтобы переход был управляемым, новое лежит **отдельно** от старого:

| Дерево | Что там | Статус |
|---|---|---|
| `src/courses/gradeN/` | новая схема: каркас, сцены, контент | здесь вся новая работа |
| `src/components/gradeN/` | существующие уроки-монолиты | legacy, трогаем только по явному решению |

Смысл разделения не в аккуратности, а в том, что **граница миграции видна в дереве файлов**.
Нельзя случайно «поправить заодно» старый урок, и всегда понятно, по какой схеме сделан
конкретный урок.

Решение методиста от 2026-08-03: работаем по 3 классу; классы 1, 2, 5, 6 не трогаем.

## Структура класса

```
src/courses/grade3/
  kit/              общий код: движок, UI, персонажи, среда, визуализаторы, схема
  scenes/DarsNN/    визуалы конкретного урока (плагины, подключаются по имени)
  content/          DarsNN.data.js — сам урок, только данные
```

Новый класс добавляется той же структурой: `src/courses/grade4/{kit,scenes,content}/`.
Каркас у каждого класса свой — визуальный язык и сюжет 3 класса не совпадают с 6-м.
Общее между классами выносится только после того, как оно **измерено** в двух классах,
а не предположено.

## Правила

1. **Импорт только через `kit/index.js`.** Прямой импорт `kit/infra.jsx`, и тем более
   чего-либо из `src/components/gradeN/DarsNN.jsx`, запрещён. Именно так возникла нынешняя
   ситуация, где раннер 32 уроков живёт внутри файла урока `Dars19.jsx`.
2. **В `kit/` нет контента.** Ни одной фразы на UZ или RU.
3. **В `content/` нет кода.** Ни JSX, ни условной логики — только данные по `kit/schema.js`.
4. **Маршрутизация остаётся в `src/lessons/gradeN.js`.** Это единственная точка, которая
   знает про оба дерева.

## Это не dev-only код

Всё здесь — рабочие React-компоненты, которые уходят в браузер к ученику. Папка не
исключается из сборки и не является песочницей. Прототипы живут в `src/lab/` (подключён к
маршрутам `/lab/*`), а всё, что вообще не относится к проекту, — в `_archive/`, откуда
импортировать запрещено.
