# scenes — визуалы конкретного урока

Папка на урок: `scenes/Dars52/ColumnCalc.jsx`. В данных экрана указывается **имя**:

```js
{ role: 'exploration', scene: 'ColumnCalc' }
```

Имя связывается с компонентом в точке сборки урока (`lessons/DarsNN.jsx`), а не в данных:
контент остаётся данными и ничего не импортирует.

**Есть первая сцена:** [Dars01/LumoCityScene.jsx](Dars01/LumoCityScene.jsx) — сцена-обрамление
урока 1 (ETALON v2 §1.3). Одна сцена, два состояния, переключает флаг `gathered`: россыпь огней
над городом (препятствие на экране 1) и собранный район из панелей, лент и огоньков (экран 15).
Пример того, как сцена строится из деталей каркаса (`LumoCityBg`, `LumoSceneCast`, `Panel`,
`Lenta`, `Chiroq`), а не рисуется заново.

## Сцена или каркас — как решить

Граница **измерена** по 19 эталонным урокам (`Dars01`–`Dars18`, `Dars21`), а не выбрана
на вкус:

| Признак | Куда | Сколько нашлось |
|---|---|---|
| Компонент встречается в ≥80% уроков | `kit/` | 67 |
| Компонент встречается ровно в 1 уроке | `scenes/DarsNN/` | 75 |

Практическое правило: **если убрать сцену и задание не изменится — это оформление, и его
место в `kit/`. Если задание рассыпается — это сцена.** Сюжет не наклеивается сверху
(ETALON_3SINF §5: «Agar rekvizitni olib tashlaganda topshiriq o'zgarmasa, syujet
integratsiyasi yetarli emas»).

Кандидаты на переезд из сцен в каркас, если подтвердится переиспользование в 2+ уроках:
`NumLine`, `RoundLine`, `ColumnCalc`, `CompareViz`.

Фоны районов Lumo (`AxborotMinorasiBg`, `RazryadPlazaBg`, `MeasureTowerBg`, `SkywayBg`,
`CountingHallBg`, `AncientHallBg`) сейчас уникальны по уроку. Вероятно, сводятся к 6 фонам
по числу районов — **но это надо измерить, а не предположить.**

## Контракт сцены

- Импортирует **только** `../../kit/index.js`. Ни `kit/infra.jsx` напрямую, ни что-либо
  из `src/components/grade3/DarsNN.jsx`.
- Не содержит текста на UZ/RU и не озвучивает: речь приходит из `content/` через `kit`.
- Получает данные через `sceneProps`, ничего не берёт из глобального состояния.
- Работает на мобильном и десктопе — [MOBIL_DESKTOP_MOSLASH.md](../../../books/MOBIL_DESKTOP_MOSLASH.md).
- Не рендерит строки вида `'24\n× 13\n────'`: это попадает в озвучку. Отображение строит
  из структурных `sceneProps`.
- Уважает `prefers-reduced-motion`.
