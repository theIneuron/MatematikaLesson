# content — сами уроки 3 класса

Один файл = один урок: `Dars52.data.js`. **Только данные.** Ни JSX, ни условной логики.
Форма — по [../kit/schema.js](../kit/schema.js), объяснение — в
[START_GRADE3.md](../../../../START_GRADE3.md) §4.2.

Пусто: первый урок по новой схеме ещё не выбран (решение методиста — «не стоит спешить»).

## Что это меняет в работе

Раньше скелет и контент были черновиками, которые выбрасывали на этапе сборки `.jsx` —
отсюда расхождения «правили каркас, а в урок уехало другое». Здесь файл, начатый как
скелет, **дозаполняется до готового урока**. Править на выходе нечего: есть один файл.

## Минимум на каждый экран

```js
{
  role: 'discovery',            // одна из 15 роли ETALON_3SINF §1 (или массив)
  interaction: 'numpad',        // mc | numpad | drag | order | match | numline | tap | build
  eyebrow: L(uz, ru),
  lead:    L(uz, ru),
  visual:  { type: 'column', a: 24, b: 13 },   // СТРУКТУРА, не строка для показа
  scene:   'ColumnCalc',                       // необязательно, из ../scenes/Dars52/
  options: [...], correct: 2,
  audio: {
    intro:      L(uz, ru),     // ОБЯЗАТЕЛЬНО, шире экранного текста
    on_correct: L(uz, ru),     // ОБЯЗАТЕЛЬНО на экране с ответом
    on_wrong:   [L(uz, ru)]    // ОБЯЗАТЕЛЬНО свой на КАЖДЫЙ неверный вариант
  }
}
```

## Три ошибки, которые схема ловит

**Аудио как пересказ экранного текста.** Так сделаны 32 урока (`Dars19–20`, `Dars22–51`):
раннер склеивал `title + text + visual + ask` и отдавал в TTS. Эталон требует обратного —
текст короткий, голос ведёт и говорит **больше** написанного. Предикат
`isAudioDerivedFromScreen` роняет такой урок.

**`visual` строкой.** `'  24\n× 13\n────\n  72'` попадает и на экран, и в озвучку: ребёнок
слышит `24 ko'paytirish 13 ──── 72`. Поэтому `visual` — объект, а рисует его сцена.

**Символы вместо слов.** `— « » % $ × = ✗ ────` в аудио — ошибка валидации, не автозамена.
Автозамена прячет проблему, ошибка заставляет написать фразу словами.

## Перед сдачей

UZ — латиница, обращение `siz`, апостроф **ASCII** `'` (не `ʻ`, не `'`, не `'`).
RU — обращение `ты`, форма без привязки к полу. Персонажи только канон:
Bit, Ra'no, Anvar, Zuhra, Jasur. Полный критерий готовности — `START_GRADE3.md` §7.
