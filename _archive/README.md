# _archive — то, что не является частью проекта

Здесь лежит материал, который **не используется работающим приложением**, но удалять его
не стали: эксперименты, документы прошлых этапов, нереализованные заготовки.

## Главное правило

**Ничто в `src/`, `public/`, `scripts/` и `index.html` не имеет права импортировать или
ссылаться на файлы из этой папки.** Проверено на момент переноса: ссылок нет. Папка
исключена из ESLint и не участвует в сборке.

Если материал отсюда снова понадобился — он выносится **обратно** в проект осознанно, а не
подключается прямо из `_archive/`.

## Что где

### `experiments/math-tools/`
Скилл детерминированных вычислений на SymPy (`cc-marketplace`). Добавлялся для
экспериментов и **никогда не был частью pipeline производства уроков**. Перенесён из
`.claude/skills/math-tools/`, поэтому больше не подхватывается как скилл сессии.
Требует Python + sympy, к самому проекту отношения не имеет.

### `notion-era/src-skills/`
Материалы времён, когда knowledge base жила в Notion. Notion отключён и не вернётся
(решение методиста 2026-08-03). Внутри:

- `CLAUDE.md` — **устаревшая копия** корневого файла, где написано, что Notion обязателен.
  Именно поэтому она перенесена: как действующая инструкция она вводила в заблуждение.
- `SETUP.md` — инструкция по подключению Notion MCP. Неактуальна.
- `coddycamp-math-claude-code/` — вложенный дубль комплекта из шести SKILL.md.

Действующие скиллы остались в `.claude/skills/`. Они тоже написаны под Notion и содержат
мёртвые ID страниц — см. `CLAUDE.md` §3.2.

### `old-prompts/`
Документы прошлых этапов. Перенесены, потому что их принимали за действующие правила:

| Файл | Почему здесь |
|---|---|
| `PROMPT_YANGI_DARS.md` | промпт создания урока под 5 класс; ссылается на несуществующие пути `src/components/DarsNN.jsx`, `src/components/Dars15.jsx`; раздел 8 предписывает копировать инфраструктуру байт-в-байт, а его инфра-код содержит баг `on_event` |
| `MATEMATIKA_LESSON_UNIVERSAL_PROMPT.md` | более старая версия того же |
| `AUDIT_KEEP_VISIBLE.md` | запись состояния уроков 1–27, не правило |
| `DIZAYN_TAHLIL.md` | audit/gap-анализ старых уроков, не правило |
| `REJA_QISMAN_DARSLAR.md` | план прошлого этапа |

**Незакрытый хвост:** `DIZAYN_STANDART_1SINF.md` (остался в корне, документ 1 класса)
ссылается на `PROMPT_YANGI_DARS.md`, `DIZAYN_TAHLIL.md` и `AUDIT_KEEP_VISIBLE.md` по старым
путям — строки 4, 5, 199, 255, 264–266. Пути не поправлены, потому что 1 класс по решению
методиста не трогаем. Правка — одна строка, ждёт решения.

### `unused-code/`
- `src-demo/dars01_3d.js` — не импортировался ни из `App.jsx`, ни откуда-либо ещё.
- `dars01_3d_demo.html`, `dars01_3d_lesson.html` — не упоминались ни в одном vite-конфиге.

Действующая 3D-лаборатория осталась в `src/lab/` — она подключена к трём маршрутам в
`src/App.jsx` и работает.

### `duplicates/`
Файлы с ` (2)` в имени — следы повторного скачивания:
`matematika_questions (2).xlsx`, `Math_1-11_Поурочно_RUz (2).xlsx`,
`LESSON_AUTHORING_PROMPT (2).md`. Оригиналы остались на своих местах.

`Примеры и шаблоны заданий (2).docx` **не перенесён**: лежит в `src/components/grade5/`,
а 5 класс не трогаем.

### `heavy/`
- **Шесть PNG из `public/assets/`** (7,9 МБ). Это нереализованный растровый комплект
  персонажей по спецификации `src/components/grade1/personaj.md`: `madina_*` — прежнее имя
  Рано, плюс `bit_happy`/`bit_hint`. Шаблон `LessonTemplate.jsx`, который их подключал по
  спеке, так и не был создан, а уроки пошли по пути inline-SVG (`RanoSVG`, `AnvarSVG`,
  `BitSVG`). Ссылок на PNG в коде нет ни одной.
  **Почему это важно было убрать:** Vite копирует всё из `public/` в `dist/`, то есть эти
  8 МБ уезжали на Vercel при каждом деплое.
- `D10_01.zip` — архив, лежавший внутри `src/components/grade1/practice/dars10/`.

## Чего здесь нет

`lms_dars01_3d_build/` остался на своём месте: это выход сборки
`vite.lms-dars01-3d.config.js`. Он снят с отслеживания git (`git rm -r --cached`) и добавлен
в `.gitignore` — пересобирается командой, хранить его не нужно.

## Про размер репозитория

Перенос не уменьшает `.git` (355 МБ): история уже содержит эти файлы навсегда. Уменьшить
можно только перезаписью истории (`git filter-repo`) — операция рискованная, отдельным
решением.
