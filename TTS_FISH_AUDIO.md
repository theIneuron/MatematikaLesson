# Озвучка уроков через Fish Audio

Как теперь устроен звук на сайте, что нужно ввести в Vercel и чем проверять.

---

## 1. Что сделано

До этой правки на сайте не было эндпоинта `/api/tts`. Уроки его вызывали (все 140 файлов,
контракт v5.2), не получали ответа и падали в браузерный Web Speech — тот самый «читает
чем-то не тем». Теперь эндпоинт есть в этом же проекте и озвучивает через Fish Audio.

| Файл | Роль |
|---|---|
| `api/tts.js` | `GET /api/tts?text=…&g=m\|f` → `audio/mpeg`. Тот же контракт, что уроки зовут с 2025 года |
| `api/_fish.js` | выбор голоса, чистка текста от языковых маркеров, вызов Fish Audio |
| `src/components/shared/LessonPage.jsx` | передаёт базу TTS **всем** урокам, а не только 6 классу |
| `vite.config.js` | тот же обработчик работает в `npm run dev`, без `vercel dev` |
| `vercel.json` | `/api/*` больше не перехватывается SPA-переписыванием |
| `scripts/tts-fish-smoke.mjs` | проверка озвучки из терминала, без браузера |

**Уроки не переписывались.** Ни один из 144 файлов с `buildTtsUrl` не тронут: контракт
запроса остался прежний, поменялось только то, кто на него отвечает.

---

## 2. Что ввести в Vercel

Project Settings → Environment Variables. Ключ вводишь сам в панели Vercel — в репозиторий
и в переписку он попадать не должен.

| Переменная | Значение | Обязательна |
|---|---|---|
| `FISH_API_KEY` | ключ из `fish.audio` → API Keys | да |
| `FISH_VOICE_M` | `reference_id` голоса | да |
| `VITE_TTS_BASE` | `self` | да |

`VITE_TTS_BASE` — это выключатель. Пока его нет, сайт озвучивает как сегодня (браузерный
голос), даже если ключ уже введён. Так сделано нарочно: неверный ключ не должен превращать
все уроки в молчание разом.

**Где взять `reference_id`.** Открой страницу голоса на `fish.audio` — адрес выглядит как
`fish.audio/m/9f8a...`. Часть после `/m/` и есть `reference_id`.

После ввода переменных нужен **редеплой**: `VITE_TTS_BASE` вшивается в бандл на сборке.

---

## 3. Один голос или несколько

**Решение методиста от 2026-08-05: один голос на всё.** Задаётся только `FISH_VOICE_M`, он
читает и русские, и узбекские, и женские реплики. Это ровно то поведение, которое даёт код
без дополнительных переменных — ничего доделывать не нужно.

Два следствия, чтобы они не всплыли неожиданно:

- Различие мужского и женского голоса в 1–3 классах на сайте пропадает (в 95 файлах
  `voiceGender: 'f'`). В LMS оно остаётся: там своя озвучка, см. §6.
- Узбекская латиница читается русской фонетикой. Насколько это терпимо — слышно в
  `scripts/tts-fish-smoke.mjs` (§4). Разумный порядок: сначала послушать четыре mp3, потом
  ставить `VITE_TTS_BASE` на продакшене.

Переменные ниже переопределяют голос точечно, если решение изменится. Код при этом не
меняется — только окружение и редеплой.

```
FISH_VOICE_M       голос по умолчанию для всего
FISH_VOICE_F       женские реплики (segment.g = 'f')
FISH_VOICE_RU_M    русский мужской          FISH_VOICE_RU_F   русский женский
FISH_VOICE_UZ_M    узбекский мужской        FISH_VOICE_UZ_F   узбекский женский
FISH_VOICE_EN_M    английский (7-8 класс)   FISH_VOICE_EN_F
```

Язык определяется по тексту сегмента: кириллица → ru, латиница → uz; если урок поставил
языковой маркер (`[Русское произношение]` и т. п.) — по маркеру. Маркер вырезается перед
отправкой, иначе голос прочитал бы его вслух.

Дополнительно: `FISH_MODEL` (по умолчанию `s2.1-pro`), `FISH_SPEED` (по умолчанию `1`; для
1–3 классов имеет смысл `0.9`), `FISH_LATENCY` (по умолчанию `normal` — лучшее качество;
`balanced`/`low` быстрее, но хуже), `FISH_MP3_BITRATE` (по умолчанию `64`, доступны `128`
и `192`).

**Бесплатный старт.** У Fish Audio есть `FISH_MODEL=s2.1-pro-free` — та же модель без карты
и без пополнения, по Fair Use, заявлено до 31 августа 2026 года; взамен нет SLA и гарантии
задержки. Для проверки на живых уроках этого достаточно. Дальше либо платная `s2.1-pro`,
либо проверить, что у них изменилось по срокам.

**Как найти id голоса списком,** если в интерфейсе неудобно:

```
node scripts/fish-find-voice.mjs Бурунов
```

Печатает `reference_id`, название, языки и автора. Символы не расходуются — это запрос к
каталогу, а не синтез. Латиницей и кириллицей результаты разные, стоит попробовать оба.

## 4. Проверка

**Из терминала, без браузера.** Скопируй `.env.example` в `.env.local`, впиши ключ и id
голоса, затем:

```
node scripts/tts-fish-smoke.mjs
```

Синтезирует четыре фразы (ru/uz × m/f), кладёт mp3 в `.tmp/tts-smoke/` и печатает, какой
голос выбран и сколько символов ушло в счёт. Отказ здесь = молчание на сайте.

**В локальном превью.** `npm run dev` — при заполненном `.env.local` уроки звучат боевым
голосом, `vercel dev` не нужен. Проверить выбор голоса, ничего не синтезируя (нужен
`TTS_DEBUG=1`):

```
curl "http://localhost:5173/api/tts?text=Bir%20ikkidan&g=f&debug=1"
```

**Ключи в URL урока.** `?tts=off` — вернуться на браузерный голос, `?tts=https://…` — взять
TTS с другого адреса. Работает без редеплоя, удобно сравнивать.

**После деплоя.** В логах функции `/api/tts` на Vercel видны отказы с причиной: `401` —
неверный ключ, `402` — кончились средства, `503` — не задан `FISH_API_KEY` или голос.
В заголовках успешного ответа: `X-Tts-Lang` и `X-Tts-Voice` (какой переменной выбран голос;
сам id не отдаётся).

## 5. Деньги и кеш

Fish Audio считает **UTF-8 байты**, а не символы. Русский текст в кириллице — 2 байта на
символ, то есть примерно вдвое дороже узбекской латиницы при той же длине.

Поэтому один и тот же сегмент не должен синтезироваться дважды. Ответ отдаётся с
`Cache-Control: s-maxage=31536000`, а ключ кеша CDN — весь URL, то есть текст + пол. Ученик
переслушал экран, второй ученик открыл тот же урок — платим один раз. Изменился текст
сегмента — изменился URL, и синтез произойдёт заново. Ошибки кешируются с `no-store`.

Длина одного запроса ограничена 1000 символами — столько же режет `buildTtsUrl` в уроках.

**Эндпоинт открыт.** Кто узнал адрес, может синтезировать за твой счёт. Ограничение —
`TTS_ALLOWED_HOSTS`: домены через запятую, без схемы (поддомены попадают автоматически, то
есть `coddycamp.uz` покрывает и `math.coddycamp.uz`). Запросы с чужих страниц получат 403.

Обратная сторона, которую надо знать заранее: проверка идёт по заголовку `Referer`/`Origin`.
Если его вырежет расширение приватности или прокси, урок получит 403 и **замолчит** вместо
того, чтобы читать. Поэтому включать имеет смысл тогда, когда расход реально начал утекать, а
не заранее. Домен LMS в список вносить не нужно — LMS этот эндпоинт не использует (§6).

## 6. LMS ничего не меняется

Проверено, а не предположено:

- уроки в LMS собираются `scripts/build-grade6-lms.mjs`, и он вызывает Vite с
  `configFile: false` — правленый `vite.config.js` в эту сборку не попадает вообще;
- `LessonPage.jsx` в бандл LMS не входит: там свой virtual entry, а корень урока получает
  `ttsApiBase` от платформы (`{ studentName, lang, ttsApiBase, voiceGender, … }`);
- `VITE_TTS_BASE` встречается ровно в одном файле — `LessonPage.jsx`, то есть только в
  оболочке сайта;
- ни один из 144 файлов уроков не изменён.

Итог: голос Fish Audio звучит на сайте, а в LMS остаётся та озвучка, которую даёт платформа,
включая женские голоса 1–3 классов.

---

## 7. Правовая сторона выбора голоса

Голос узнаваемого актёра — это не то же самое, что абстрактный синтетический голос: на
коммерческом школьном продукте он требует согласия правообладателя, независимо от того, что
модель лежит в открытой библиотеке Fish Audio. Технически интеграция от выбора голоса не
зависит — сменить `FISH_VOICE_M` на любой другой `reference_id` можно в один приём, без
правок кода. Решение о конкретном голосе — за методистом и Фузайлом.

## 8. Физика — отложено

Решение методиста от 2026-08-05: физику подключаем позже. Ниже — что понадобится, чтобы не
разбираться заново.

Предмет `fizika` в `src/lessons/index.js` объявлен, но уроков в нём нет ни одного — вся
математика, информатика и физика ходят через один и тот же `/api/tts` этого проекта. Как
только появятся уроки физики, они озвучиваются тем же эндпоинтом без дополнительной
настройки. Если физика живёт в **другом** проекте Vercel, у него два пути: скопировать туда
`api/tts.js` + `api/_fish.js` и те же переменные, либо передать урокам
`ttsApiBase=https://<домен-математики>` и переиспользовать этот эндпоинт (тогда домен физики
надо внести в `TTS_ALLOWED_HOSTS`).
