**Приборы, которые уже есть.** Полный список — в эталоне §4.2. Крупные:

- `TransformChain` — цепочка равносильности (Б2, 9 уроков);

- `OutcomeTree` — дерево исходов, сумма и произведение рядом (Б3);
- `FrequencyBoard` — четыре режима: клетки, столбики, машина испытаний, облако точек (Б3);

  руками**: тяга вбок ведёт образующую вокруг оси, тяга вверх меняет наклон взгляда.
  Включается уроком через `solid.interactive`.

## 3. Чем проверять

Четыре скрипта плюс стенд. Первые три — секунды, четвёртый — минуты.

```
node scripts/grade11-lesson-audit.mjs                 # контракт эталона: роли, теги
node scripts/grade11-audio-lang-check.mjs             # языки, выдержка кадров, символы
node scripts/grade11-styles-check.mjs                 # стили
GRADE11_PORT=5263 GRADE11_LANGS=ru GRADE11_ONLY=telefon-393 \
  node scripts/grade11-noscroll.mjs dars27            # вёрстка
```

**`noscroll` НЕ поднимает сервер сам** — нужен запущенный
`npx vite --port 5263 --strictPort`. Без него `ERR_CONNECTION_REFUSED` выглядит как
поломка урока, а урок цел. И наоборот: брошенные dev-серверы копятся и съедают
память, после чего новый не стартует вовсе.

**Стенд `probe/spin.html`** (сервер на 5299) — смотреть чертёж ДО сборки урока.
За блок Б4 он поймал шар-сигару, непрозрачные заливки, развёртку не в масштабе,
ложную дугу внутри тела и призму, нарисованную как цилиндр. Ни один из этих
дефектов проверка вёрстки увидеть не может: она меряет габариты, а не смысл.

## 4. Открытый долг — читать перед сдачей класса

1. **Языки.** Уроки 26 и 29–33 проверены только на русском. Узбекский длиннее
   русского на 10–20%, обрезки там почти наверняка есть. Уроки 16–24, 27, 28 —
   на трёх языках.
2. **Только телефон.** Ни один урок Б4 не мерялся на планшете и десктопе. Полный
   контракт — шесть размеров × три языка.
3. **`FREE_NAV = true`** в `core.jsx` — режим разработки. Перед сдачей `false`.
4. **Геометрия учебника не загружена.** По урокам 28–33 источника нет (решение
   методиста 2026-08-15 — идти без учебника). Узбекские термины стереометрии
   стоят как **draft** и требуют валидации узбекским методистом математики.
   Есть только «Призма и цилиндр» (ч. 1, стр. 146–184) и объёмы через интеграл
   (ч. 2, стр. 4–8).

## 5. Грабли, которые дороже всего стоили

- **`L()` в данных прибора кладёт экран.** Выбирают не только символы, но и слова
  («медиана», «общая причина»). Закрыто внутри приборов через `isTri()`:
  `SignFill`, `BuildExpr`, `AnswerValue`. Ключ подсказки допускает форму массива.
  Признак в консоли: сначала «two children with the same key», потом «Objects are
  not valid as a React child».
- **Хуки выше ранних `return`.** В `SpinBoard` пять режимов и два ранних выхода;
  состояние поворота обязано стоять первыми строками, иначе React падает при
  смене режима.
- **Кириллица внутри узбекских слов** (`emас`, `necha` с русской «а») — за сессию
  пять раз. Глазами неразличимо, ловит только скрипт озвучки.
- **Числа рисунка задаёт урок, а не `Math.random`** — иначе каждая загрузка даёт
  другую картинку и проверка вёрстки не ловит ничего.
- **Не коммитить на границе.** Урок 33 один прогон показал чисто, следующий — 9 px
  превышения. Нужен запас, а не одно зелёное измерение.
