## 2. ЧТО ДЕЛАТЬ ДАЛЬШЕ — ДВА ДЕФЕКТА ОТ МЕТОДИСТА (2026-08-22, вечер)

### 2.1. Шрифт варианта отличается внутри одного вопроса

**Что видно.** В вопросе четыре варианта. Вариант A набран моношрифтом математики, B, C, D —
прозой. Выглядит как сбой. Методист: «стиль шрифта должен быть одинаковым везде, можно
править глобально».

**Причина найдена.** `core.jsx:719`

```
const MATHY_RE = /[0-9=<>+−∞·×≤≥≠]/
export const looksMath = (v) => typeof v === 'string' && MATHY_RE.test(v)
```

`Options` (core.jsx:1327) вешает класс `g7-opt-math` на КАЖДЫЙ вариант отдельно:
`looksMath(item.label) || numeric`. Достаточно одной цифры в строке — и вариант уезжает в
моношрифт. Вариант A «Bitta harf ishlatgani: ikkinchi kattalik 40 ayirish x» содержит «40»,
поэтому он математический, а остальные — проза.

**Куда смотреть при правке.** Решение принимать на уровне ВОПРОСА, а не варианта: либо все
варианты математические, либо все прозаические. Варианты решения:
- считать вопрос математическим, только если ВСЕ варианты `looksMath`;
- либо ужесточить `looksMath`: не «есть цифра», а «символов больше, чем слов».

Второй вариант влияет шире — `looksMath` используется и в других местах, проверить.

### 2.2. Текст слипается: «jami 40 kg»

**Что видно.** В рамке хука надпись `jami 40 kg` рендерится так, что буква перед числом
налезает на цифру — читается как «jamㅗ0 kg».

**Причина найдена.** `Fx` разбивает строку и оборачивает числа в `<span class="g7-fxnum">`
(core.jsx:785). Стиль (core.jsx:2268–2270):

```
.g7-fxnum { font-family: MATH_FONT; font-weight: 800; }
.g7-ask .g7-fxnum, .g7-qpill .g7-fxnum, .g7-hint .g7-fxnum,
.g7-fb-body .g7-fxnum, .g7-sumcard-ul .g7-fxnum { font-size: 1.16em; }
```

То есть внутрь прозы вставляется число ДРУГИМ шрифтом, жирнее и на 16% крупнее. Метрики не
совпадают, горизонтального зазора нет — глифы наезжают.

**Куда смотреть при правке.** Дать `.g7-fxnum` небольшой боковой зазор внутри прозы
(`margin-inline: .06em` или `padding-inline`), либо убрать увеличение 1.16em там, где число
стоит в строке прозы. Проверять на узбекском — там слова длиннее и стыков больше.

**Связанная память:** `[[podpis-formula-yoki-soz-sklejka]]`,
`[[razdelitel-tochka-sedaet-umnozhenie]]` — та же порода: склейка формулы и слова.

## 5. ГРАБЛИ, НА КОТОРЫЕ Я НАСТУПИЛ СЕГОДНЯ

1. **Обратный апостроф внутри `STYLES` рвёт шаблонную строку** — урок открывается ПУСТОЙ
   страницей (`dl is not defined`, `expr is not defined`), а `npm run build` при этом
   ЗЕЛЁНЫЙ. Ловит только `check-grade7`. Тронул `core.jsx` — запусти его, он мгновенный.
2. **Браузерная проверка может молча проходить.** Мой аудит врал трижды: уходил из урока по
   кнопке «Список уроков»; стоял на первом слайде (у кнопки «Дальше» в 7 классе НЕТ
   `data-next`, нужна «последняя активная кнопка в навигации»); считал дефектом любой спилл,
   даже там, где блок не режет. Правило: сверять номер слайда (`N / 15`) и считать выход из
   урока ошибкой проверки.
3. **Замок ответа блокирует кнопки, пока идёт инструкция.** В headless озвучки нет, и замок
   держит до страховочных 12 секунд на экран. Пока свободный переход включён — жать «Дальше»
   по названию и не отвечать вовсе.
4. **heredoc в bash съедает обратный слэш** — скрипты с `\'` и `\n` писать через Write, не
   через heredoc.
