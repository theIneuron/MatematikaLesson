# Справочник по 3 классу: файлы, термины, диагностика

> Для методиста. Отвечает на три вопроса: **что это за файл**, **что значит это слово**,
> **где искать, когда сломалось**. Рабочий порядок — в [START_GRADE3.md](START_GRADE3.md).

---

## 1. Как открыть урок

```
npm run dev
```

Откроется по адресу `http://localhost:5173`. Урок 3 класса — по схеме
`/<класс>/<предмет>/<раздел>/<slug>`:

```
http://localhost:5173/3-sinf/matematika/nazariy/dars01-yuzlik-onlik-birlik
```

`slug` каждого урока лежит в [src/lessons/grade3.js](src/lessons/grade3.js). Проще: открыть
`localhost:5173`, выбрать 3 класс → математика → «Nazariy mashg'ulotlar» → урок.

**Урок 1 по новой схеме** — отдельный адрес, старый урок остался на месте:

```
http://localhost:5173/3-sinf/matematika/nazariy/dars01-yuzlik-onlik-birlik-v2
```

В нём три языка: переключатель `UZ / RU / EN` в правом верхнем углу (виден только в локальном
просмотре, ученику его не показывают — язык приходит от платформы). Если текста на нужном
языке нет, на экране появится пометка вида `⟨en?⟩` — это сделано намеренно, чтобы пропуск
нельзя было не заметить.

**Консоль браузера — главный инструмент.** `F12` → вкладка Console. Если урок не открылся
или ведёт себя странно, там будет красная строка с названием файла и номером строки. Эта
строка — половина решения задачи.

## 2. Три поколения уроков 3 класса — почему это важно знать первым

В 3 классе **51 урок, и они устроены по-разному**. Прежде чем искать баг, посмотри, к какому
поколению относится урок: искать надо в разных файлах.

| Уроки | Устройство | Размер файла | Где искать баг |
|---|---|---|---|
| **урок 1 v2** (новая схема) | данные отдельно, общий каркас отдельно | данные 1270 строк, точка сборки 25 | текст — в `content/Dars01.data.js`, поведение — в `screens/`, механика — в `kit/` |
| **Dars01–18, 21** | каждый урок самодостаточный: свой движок, свои стили, свои экраны | 5 200–7 200 строк | внутри самого файла урока |
| **Dars19–20, 22–32** | данные + общий раннер `Grade3LessonShell` | 90–110 строк | текст — в файле урока, поведение — в `Dars19.jsx` |
| **Dars33–41** | данные + раннер `GeometryLesson` | 5 строк | `Grade3GeometryBlock.jsx` |
| **Dars42–51** | данные + раннер `FinalBlockLesson` | 2 строки | `Grade3FinalBlock.jsx` |

**Ловушка:** раннеры лежат **внутри файлов уроков**, а не отдельно. `Grade3LessonShell`
живёт в `Dars19.jsx`, и от него зависят 32 урока. Правка «урока Dars19» может сломать уроки
с 20-го по 51-й. Более того, `Dars19.jsx` берёт сцены из `Dars01.jsx`, `Dars02.jsx`,
`Dars09.jsx`, `Dars18.jsx` — значит правка Dars01 тоже способна их задеть.

**Практическое правило:** тронул `Dars01`, `Dars02`, `Dars09`, `Dars18` или `Dars19` —
проверь ещё `Dars22`, `Dars33`, `Dars42`.

Уроки Dars01–18 и 21 — эталонные: у них аудио написано вручную. Уроки Dars19–51 сделаны
раннерами, которые собирают озвучку склейкой экранного текста — это зафиксированный долг,
см. `START_GRADE3.md` §6.2.

## 3. Анатомия файла урока (на примере `Dars01.jsx`, 6230 строк)

Файл читается сверху вниз как книга. Номера строк — для Dars01, в других уроках сдвинутся,
но **порядок разделов везде одинаковый**.

| Строки | Раздел | Что там | Тебе нужно? |
|---|---|---|---|
| 1–3 | импорты | что урок берёт извне | нет |
| 5–31 | **шапка-описание** | тема, сюжет, ядро, реквизит, механика по экранам, misconception'ы | **да — читать первым** |
| 36–48 | `T` — палитра | цвета: `accent` оранжевый, `ink` текст, `bg` фон | иногда |
| 54–160 | конфиг и TTS | как урок обращается к озвучке и звукам | нет |
| 161–225 | язык и мобильный | переключатель UZ/RU, счётчик звёзд, зум на телефоне | нет |
| **226–550** | **AudioEngine** | движок озвучки: очередь фраз, ожидание событий | **не трогать** |
| 551–885 | базовые компоненты | кнопки, `Stage`, `FeedbackBlock`, `QuestionScreen` | редко |
| **1023–…** | **`CONTENT`** | **весь текст урока: RU, UZ, аудио** | **да — здесь правится текст** |
| … | визуализаторы и экраны | `Screen0`, `Screen1`, … — что видно на каждом слайде | иногда |
| 4029 | `export default` | корневой компонент, собирает урок целиком | нет |
| 4127–6230 | `STYLES` | CSS: отступы, размеры, анимации | редко |

### Как найти нужный экран в `CONTENT`

`CONTENT` — это оглавление урока. Ключи `s0`, `s1`, `s2`… — номера экранов:

```js
s0: {
  eyebrow: { ru: 'Миссия',  uz: 'Missiya' },          // надпись-ярлык сверху
  lead:    { ru: 'Корабль сел…', uz: "Kema qo'ndi…" }, // текст на экране
  q:       { ru: 'Как быстро…?', uz: 'Qanday tez…?' }, // вопрос
  opt0: …, opt1: …, opt2: …,                           // варианты ответа
  audio: {
    intro:      { ru: […], uz: […] },   // что говорит голос при появлении экрана
    on_correct: { ru: '…',  uz: '…' },  // что говорит при верном ответе
    on_wrong:   { ru: '…',  uz: '…' },  // что говорит при неверном
  }
}
```

Правило: **текст правится здесь и только здесь.** Если фраза вписана прямо в разметку
экрана, она не переведётся на второй язык — это баг, а не вариант.

## 4. Словарь терминов

### Про код в целом

| Термин | Что это простыми словами |
|---|---|
| `.jsx` | файл с кодом урока: логика + разметка в одном |
| **компонент** | самостоятельный кусок экрана со своим именем. `Screen5` — пятый слайд, `NumPad` — цифровая клавиатура |
| **props** | настройки, которые компонент получает снаружи. Урок получает от платформы `lang` (`'ru'` или `'uz'`) |
| **state** (`useState`) | память компонента: что выбрал ребёнок, показан ли разбор |
| **hook** | функция с именем на `use…` (`useAudio`, `useIsMobile`). Готовый механизм, подключаемый к экрану |
| `const` | объявление значения. `const CONTENT = {…}` — «здесь лежит контент» |
| `import` / `export` | «взять из другого файла» / «отдать другим файлам» |
| **рендер** | момент отрисовки экрана. Ошибка «в рендере» = белый экран |

### Про содержание урока

| Термин | Что это |
|---|---|
| `CONTENT` | все тексты урока: RU, UZ, аудио. Главное место для правок |
| `T` | палитра цветов. `accent` `#FF4F28` — фирменный оранжевый |
| `STYLES` | CSS: размеры, отступы, анимации |
| `Screen0…ScreenN` | слайды по порядку. `ScreenCase` — жизненная задача, `ScreenMing` — тысяча |
| `QuestionScreen` | универсальный экран «вопрос + варианты + разбор» |
| `Stage` | рамка слайда: заголовок, полоса прогресса, кнопки «назад/дальше» |
| `FeedbackBlock` | блок разбора, появляющийся после ответа |
| `FactCard` | карточка «Bilasizmi?» — награда с научным фактом |
| **misconception** | типичная неверная мысль ребёнка. Каждый неверный вариант должен отвечать конкретной misconception, а не быть случайным |
| `on_wrong` / `explain_wrong` | разбор неверного ответа. Указывает, **на какой признак смотреть**, но не даёт ответ |
| **роль экрана** | педагогическая задача слайда (проблема, открытие, правило, обратная задача…). 15 роли перечислены в `ETALON_3SINF.md` §1 |
| **канон персонажей** | Bit, Ra'no, Anvar, Zuhra, Jasur. Новых не добавляем |
| **сюжет Lumo** | планета Бита, 6 районов = 6 блоков программы. `SYUJET_3SINF.md` |

### Про озвучку — здесь чаще всего баги

| Термин | Что это |
|---|---|
| **TTS** | синтез речи. Локально — Web Speech (голос браузера, заглушка), на сайте — сервер по контракту v5.2 |
| `AudioEngine` | движок озвучки: держит очередь фраз и решает, когда следующая |
| **сегмент** | одна фраза в очереди. Правило: один сегмент = одна мысль |
| `trigger` | когда фраза звучит: `on_mount` — при появлении экрана, `after_previous` — сразу после предыдущей, `on_event:…` — **только когда произошло событие** |
| `waits_for` | фраза дожидается действия ребёнка (нажал вариант, нажал «Проверить») |
| `pushOneOff` | вставить фразу вне очереди — так звучит разбор ответа |
| `voiceGender` / `g=f` | пол голоса. В началке женский |
| `SFX` | короткие звуки «верно/неверно» |
| **склейка** | когда озвучка собирается автоматически из экранного текста. Так работают Dars19–51, и это нарушает эталон: голос должен говорить **больше** написанного, а не повторять |

### Про навигацию и проверку

| Термин | Что это |
|---|---|
| `FREE_NAV` | `true` — кнопка «Davom» активна всегда, ребёнок проматывает объяснение. `false` — открывается после озвучки. В релизе должно быть `false`. Сейчас `true` в Dars01–19, 21 |
| `useAdvanceGate` / `useCanAnswer` | механизмы, решающие, можно ли уже отвечать и идти дальше |
| **shuffle** | перемешивание вариантов, чтобы верный не был всегда первым |
| `LangContext` / `useT` | переключатель UZ/RU |
| `slug` | адрес урока в ссылке: `dars01-yuzlik-onlik-birlik` |
| **реестр** | `src/lessons/grade3.js` — список уроков: номер, slug, тема, описание. Урока нет в реестре → его нет на сайте |

### Про работу и публикацию

| Термин | Что это |
|---|---|
| `npm run dev` | локальный просмотр |
| `npm run build` | проверка, что проект собирается. **Обязательно перед push** |
| `dist/` | результат сборки, попадает на сайт |
| **commit** | сохранить изменения в историю |
| **push** | отправить на GitHub → оттуда на Vercel. **Push = публикация** |
| **untracked** | файл есть на диске, но не добавлен в историю. Если код его использует — на Vercel сборка упадёт, хотя локально работало |
| **eslint** | автопроверка кода на подозрительные места |
| `_archive/` | материал вне проекта. Оттуда ничего не подключается |

## 5. Диагностика: симптом → где смотреть

| Что видишь | Причина | Куда смотреть |
|---|---|---|
| **Белый экран** | ошибка в коде при отрисовке | `F12` → Console, красная строка с файлом и номером |
| Белый экран после правки текста | сломана структура `CONTENT`: пропала запятая, кавычка или закрывающая скобка | последняя правка в `CONTENT` |
| **Экран пустой, а остальные работают** | в `CONTENT` нет ключа этого экрана (`s7` есть в коде, нет в контенте) | сравнить ключи `s0…sN` с экранами |
| **Урока нет на сайте** | не добавлен в реестр | `src/lessons/grade3.js` |
| Урок открывается по ссылке, но **404 при обновлении** | нет SPA-переадресации | `vercel.json` (создан) |
| **Голос молчит** | локально: браузер блокирует звук до первого клика. На сайте: бэкенд TTS | кликнуть по странице; на сайте — вопрос к бэкенду, не к уроку |
| **Голос читает мусор** (`──── ✗ +`) | символы попали в озвучку | аудио-поля в `CONTENT`; у Dars19–51 — склейка в `Dars19.jsx:470` |
| **Голос читает то же, что написано** | озвучка = склейка экранного текста | поколение урока (§2). Эталон требует, чтобы голос говорил шире |
| **Объяснение звучит раньше, чем ребёнок ответил** | сегмент `on_event:` не дождался события | в 3 классе починено (`Dars02.jsx:342–353`). Если появилось — сравнить движок с этим местом |
| **После ответа разбор не озвучен** | сломан `pushOneOff` | `Dars02.jsx:381–386` — там должно быть `playNext(true)` |
| **Кнопка «Davom» не включается** | ждёт конца озвучки, а озвучка не завершилась | `useAdvanceGate`, `audio.done`, значение `FREE_NAV` |
| **Ребёнок проматывает объяснение** | `FREE_NAV = true` | строка `const FREE_NAV` в файле урока |
| **Верный ответ всегда первый** | нет перемешивания | `shuffle` в файле урока |
| **Разбор не появляется или дёргается** | нарушен приём с двойным `requestAnimationFrame` | `FeedbackBlock`, ~строка 628 |
| **Не видно на телефоне** | нарушен мобильный контракт | `src/books/MOBIL_DESKTOP_MOSLASH.md`, `useMobileZoom` |
| **Цвета не как в остальных уроках** | своя палитра | `T` в начале файла: `accent #FF4F28`, `ink #0E0E10`, `bg #F6F4EF` |
| **Апостроф выглядит иначе** | не ASCII `'`, а `ʻ` / `'` / `'` | UZ-строки в `CONTENT` |
| **В узбекском попались русские буквы** | кириллица в UZ | UZ-строки в `CONTENT` |
| **Обращение «ты» вместо «siz»** | нарушен регистр | UZ-строки: `siz`, не `sen` |
| Локально всё работает, **на Vercel сборка падает** | нужный файл не добавлен в git | `git status`, раздел untracked |
| **Кнопка «Дальше» не включается никогда**, и звук выключен | экран ждёт озвучку, которая не сообщила о завершении | новая схема: часовой `stalled` в `useAudio`; правило — ETALON §10.1 |
| **Рамка на экране пустая** | в данных механика есть, а экран её не умеет | `screens/`: механика из `interaction` должна быть обработана |
| **Урок не открывается вообще, белый экран** | в модуле каркаса константа объявлена раньше того, на что ссылается | Console: `Cannot access ... before initialization` — смотри порядок `const` в файле |

## 6. Правила безопасной правки

1. **Текст — только в `CONTENT`.** Фраза, вписанная в разметку экрана, не переведётся.
2. **Аудио — отдельные поля, а не копия экранного текста.** Голос ведёт и говорит больше.
3. **`AudioEngine` не трогать.** В 3 классе он единый во всех 19 эталонных уроках и уже
   содержит правильное поведение. Любая «мелкая правка» в нём ломает озвучку во всём классе.
4. **Правишь Dars01/02/09/18/19 — проверь Dars22, Dars33, Dars42.** Они зависят от этих
   файлов (§2).
5. **После правки — `npm run build`.** Проходит → можно коммитить.
6. **Перед push — `git status`.** Нет untracked-файлов, которые использует код.
7. **Символы в озвучке пиши словами.** `×` → «ko'paytirish», `=` → «teng». Никаких
   `— « » % $ ✗ ────`.
8. **Сомневаешься — не удаляй, перенеси.** Для этого есть `_archive/`.
9. **Сборка и линт не заменяют прокликивание.** `npm run build` проходил и на уроке, который
   не открывался вообще, и на уроке с пустой рамкой на девятом экране. Открой урок, пройди
   его до конца, посмотри в консоль. Быстрая проверка на самое частое: **выключи звук и
   пройди урок** — так ловятся экраны, которые не отпускают ребёнка.

Для нового урока (`src/courses/grade3/`) правила 1, 2, 7 те же, но адреса другие: текст — в
`content/DarsNN.data.js`, поведение — в `screens/`, механика — в `kit/`. Проверка данных:
`node scripts/validate-grade3.mjs --data src/courses/grade3/content/Dars01.data.js`.
